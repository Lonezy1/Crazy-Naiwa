# Asset Layout

- `icon.svg`: application icon.
- `character/`: source sprites, approved variants, and animation sheets.
- `audio/`: sound effects and music, grouped by use.
- `fonts/`: bundled fonts with license notices.
- `ui/`: interface artwork that is not drawn by the shared theme.

Keep source files and runtime-ready files together only when Godot imports them directly. Record each external asset's origin, license, attribution requirements, and edits in a neighboring `README.md`. Do not add files from the local `奶蛙素材/` directory until their license and provenance are verified.
