# Crazy Naiwa

基于 Godot 4 的抽象奶蛙桌宠原型。

## 当前版本

`0.1.0`（MVP）

## 当前能力

- 透明、无边框、置顶窗口
- 程序绘制的奶蛙占位角色
- 待机呼吸、随机眨眼、重力弹跳和边缘反弹
- 鼠标拖拽窗口、点击弹跳、透明区域鼠标穿透
- 右键菜单：回到屏幕右下角、置顶开关、退出
- `user://crazy_naiwa.cfg` 持久化置顶设置和窗口位置

## 代码边界

- `Main.gd`：系统窗口、菜单、鼠标事件与桌面位置
- `FrogVisual.gd`：角色绘制、动画状态、碰撞命中区与点击穿透形状
- `PetSettings.gd`：少量用户设置的本地配置读写
- `PetTheme.gd`：角色与菜单共用的颜色和悬浮状态样式

数据流保持为“鼠标输入 → 窗口/角色状态 → 角色渲染”；没有数据库，也没有旧配置格式迁移。当前没有设置下拉框或弹窗，因此不引入无用控件状态。

## 素材接入边界

角色图片、动画帧、音效和字体尚未纳入工程；工作区另有本地素材目录，但素材授权和透明处理尚未确认，因此不会随代码提交。正式素材应放在 `assets/` 下，并由角色资源模块接入；窗口逻辑与持久化逻辑保持独立。

## 运行

使用 Godot 4.7 或更新版本打开项目根目录，运行主场景。

无界面运行自动化测试：

```powershell
godot --headless --path . --script res://tests/test_settings.gd
```
